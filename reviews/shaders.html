Key points

What matters most, in order.

1

Verified, not vibes

Cloned, pnpm install, full suite: 267 test files, 1,780 tests, all passing in 26 seconds. For a graphics library that is an unusually serious correctness surface — engine, GPU layer compilation, and per-component behavior are all covered.

2

One engine, generated bindings

All five framework packages are generated from packages/core — one folder per effect, single source of truth. React, Vue, Svelte, Solid and vanilla JS can never drift apart, which is exactly where most multi-framework libraries rot.

3

Agent-wired three ways

An MCP server (npx shaders install-mcp) for find/install/edit, a CLI that writes real component files into your repo with a lock file — diffable, reviewable, no runtime fetch — and llms-full.txt carrying every prop, default and range. Agent-installed effects are just code in your tree.

4

Custom effects are first-class

defineShader({ name, props, paint: wgsl`...` }) — a plain object with typed prop transforms and a WGSL paint function, mountable via <CustomShader> like any built-in. The escape hatch is the same object model as the library itself.

Composable GPU layer tree

<Shader> renders the canvas; children are layers evaluated top-to-bottom and blended on the GPU. Gradients under distortions under cursor trails, with masks — composition is declarative, and the shaders.com design editor emits exactly this tree as framework code.

import { Shader, LinearGradient, CursorTrail } from 'shaders/react'

<Shader className="w-full h-64">
  <LinearGradient colorA="#0f172a" colorB="#7c3aed" />
  <CursorTrail />
</Shader>

The shaders.com editor is an infinite canvas: stack components, tune props with real controls, drive them from cursor or timeline, then Export Code for your framework. Free with an account; Pro adds 1,000+ presets and watermark-free HD rendering.

Custom components

export const Halo = defineShader({
  name: 'Halo',
  props: {
    color:  { default: '#ffd166', transform: transformColor },
    center: { default: { x: 0.5, y: 0.5 }, transform: transformPosition },
    radius: { default: 0.6 },
  },
  paint: wgsl`
    let d = length((uv - center) * vec2f(aspect, 1.0)) / radius;
    return vec4f(color.rgb, 1.0 - smoothstep(0.8, 1.0, d));
  `,
})

packages/core holds the engine: shaderRegistry, GPU layer compilation via TypeGPU, customShaders, presetRenderer, performanceTracker, and the 199 component folders. Framework packages wrap core via codegen.

packages/shaders is the umbrella npm package with subpath exports (shaders/react, shaders/vue, shaders/std, ...) plus the CLI. Prop transforms (transformColor, transformPosition) normalize declarative props into GPU uniforms; paint is WGSL compiled through TypeGPU's typed resolution.

The public repo is a week old (created 2026-09-29), but it's the open-sourced evolution of an established platform — v4.0.0 on npm, "16,000+ design engineers" predates the repo going public.
