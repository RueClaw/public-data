Key points

What matters most, in order.

1

Meaning and exact strings belong together

Shared 768-dimensional embeddings rank document, image and media segments. SQLite FTS5 rescues names and identifiers. Search scans all vectors, so large collections need real memory and latency measurements.

2

Local does not mean secret-proof

No upload path was found in inspected core code, but no traffic capture was performed. The ordinary SQLite index contains extracted text and paths. Secret filename filters are incomplete, and git-ignore filtering fails open if git cannot list files.

3

Good engineering signals, young release history

Model hashes, native runtime commit pins and reference-vector tests are useful safeguards. The latter skip without models; the only checked-in GitHub Actions workflow distributes Homebrew releases, rather than running a test matrix.

Location-aware retrieval

PDF pages, document passages, 30-second audio windows and video frames retain page/time metadata. Long documents get staged completion. This is retrieval, not an answer-generating chatbot. See Indexer.

Separate code search

Code is opt-in and stored in a second database. Notebook outputs are omitted; definition navigation uses text heuristics rather than compiler analysis. See CodeExtractor.

Compatibility over needless rebuilding

Model fingerprints and vector versions distinguish output changes from runtime upgrades. Reference tests require cosine agreement of at least 0.999 but skip when models are absent. See reference tests.

Folders → crawler/rules → format readers → embedding helper → SQLite segments/FTS → full vector scan plus keyword scoring → results. Searcher uses modality-adjusted semantic scores and word-coverage bonuses; it is not an ANN service.

Trust boundaries

Helpers use pipes and same-user processes, not an HTTP endpoint or adversarial sandbox. The ordinary SQLite database stores paths, excerpts and FTS text without application-layer encryption. Database and entitlements show why OS permissions, disk encryption and backup policy matter.

Rules filter filenames/extensions, not arbitrary secrets inside documents. Crawler allows files when git cannot supply its kept-file list. Exclude sensitive folders explicitly.

Supply chain and robustness

Model downloads are revision/hash-pinned; llama.cpp is checked against an exact commit. Portable vendor downloads lack digest checks. The watchdog contains runaway indexing by ending helpers at memory/time thresholds, not by sandboxing parsers.

Verdict

The call, and why.

⚠️ Interesting

Pilot on small, non-sensitive folder sets. The hybrid retrieval and vector-compatibility design are thoughtful, but the public release is days old and exclusion heuristics are not a security boundary. Static review only: no builds, tests, model inference, performance or network behavior were independently exercised.
