Key points

What matters most, in order.

1

Jev picks the presentation, per turn

A small decision model (TypeSafe's Jev) chooses text vs. A2UI native components vs. Open Generative UI for each user turn — presentation selection as a fixed-option-set decision, not prompt convention. Failures surface instead of silently rerouting. The second substantial Jev consumer we've reviewed, and the better-scoped one.

2

Sandboxed generative UI with real boundaries

Generated HTML/CSS/JS streams into an isolated iframe (sandbox="allow-scripts", no same-origin), tool parameters arrive in a fixed order, host communication crosses a validated bridge only on user action, and there's deliberately no patch API — every artifact stays immutable.

3

BYOK done carefully

Keys live in browser memory only (never storage, never chat state or checkpoints), LangSmith tracing is disabled for BYOK requests, connection test before save — plus the honest warning: only use BYOK on a deployment whose operator you trust.

4

A pattern source, not a product

Verified: 159/159 tests pass. But it's demo-grade — sample data, two required provider keys (OpenAI + TypeSafe), thin coverage relative to surface. The docs say it themselves: docs/bring-to-your-app.md is the intended path. Mine it; don't deploy it as-is.

Three answer shapes

  • Understand — 3D explanations with labeled controls (pitch/roll/yaw airplane demo)
  • Compare — tables that become charts on follow-up
  • Make a tool — working calculators, planners, live-tiled maps

Fixed parameter order for generated UI

initialHeight → placeholderMessages → css
→ html → jsFunctions → jsExpressions

Local controls run inside the sandbox; user-initiated follow-ups pass selected values through the validated bridge into a new agent turn. No cross-call patch API — prior outputs are immutable artifacts.

Verdict

The call, and why.

⚠️ Interesting

The cleanest reference implementation of agent-generated interactive UI: Jev-routed renderer selection, genuinely sandboxed streaming iframes with immutable artifacts, and unusually careful BYOK hygiene — 159/159 tests pass. But it's a template: demo data, two required provider keys, thin coverage for the surface. Use it as the pattern source for building generative UI into your own app.
