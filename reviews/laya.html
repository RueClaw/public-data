Key points

What matters most, in order.

1

Typed does not mean correct

Choice, ordinal score and yes/no probabilities eliminate generated-JSON parsing. Classification errors remain; score is an expected level, not a probability of danger.

2

A useful local decision component

Routing selects English, multilingual or typed-decisions checkpoints. Confidence fields differ in meaning; calibrate answer_confidence and retain host-owned approval and fallback rules.

3

Evidence limits matter

The published 51-language sweep reports 0.4008 macro accuracy, not universal multilingual reliability. Jev comparisons are unmatched; the benchmark page says the 0.766 headline lacks a committed result file.

Decision schemas

Choice returns a known option; score is the expected ordinal index; noul is yes probability. Legacy confidence is entropy for choice/score, unlike answer_confidence. Never copy thresholds blindly from Jev.

Evidence, not promises

Reported T4 latency is 32.8 ms p50 for one question, not cold-start or service p99. Historical indirect-injection tests on older packages report full-rule recall 0.76 and false-positive rate 0.29; this review did not retest v0.4.11. Guard scores are not an authorization boundary.

Benchmark caveats · Guardrail limits

Router → bounded question rows → encoder → typed head

Each question combines state, instructions and options. A bidirectional encoder and marker-scoring head produce probabilities without token generation. Batched questions still add work; long scanning and option tournaments use multiple passes.

Trust boundaries

Weights download from Hugging Face; revision pins and digest maps are opt-in. Safetensors reduces serialization risk, not all model/runtime risk. The recommended digest map omits a tokenizer configuration that may be rewritten. Remote MCP sends the full supplied state to its configured server, optionally with a bearer key.

Do not expose the default server

Bare laya-serve binds all interfaces with optional, unset authentication. Use private binding, LAYA_API_KEY, TLS and edge rate/deadline limits. Its body, question, batch and concurrency caps are useful but batch chunking does not bound total occupancy of the single inference worker.

Controlled pilot

Pin checkpoint revisions and tested dependencies; pre-download reviewed assets. Test language, context truncation, cold starts and resident-model churn. Use held-out evaluation and separate calibration data. Keep callbacks/traces away from sensitive text unless explicitly intended.

Apache-2.0 source permits reuse under its terms; independently check model and dependency terms. No weights were downloaded or license-audited here.

Verdict

The call, and why.

⚠️ Interesting

Pilot for bounded classification, not a security authority. Typed outputs and local inference are valuable, but correctness, calibration and latency must be measured on your traffic. Static review only: no models downloaded, source tests executed or inference reproduced.
