Key points

What matters most, in order.

1

Training, not just rendering

COLMAP input, stereo initialization, Slang kernels, densification, live viewing and PLY export are implemented. CUDA/PyTorch-free training still needs native GPU libraries and Python packages.

2

10 seconds excludes setup

CSV arithmetic confirms 10.51223 s / 27.13068 dB for RTX 4090 Ultrafast and 22.68185 s / 27.90035 dB for Quality. Nine-scene loop means are not photo-to-model times or independent performance reproductions.

3

License and variance matter

Default Ultrafast masks are non-commercial research/evaluation assets. Single seeds, run-to-run visual differences, historical benchmark revisions and loop-end rather than peak VRAM qualify the headline.

Implemented pipeline

Python schedules projection, tile sorting, blending, loss, backward passes, Adam and growth. BF16 moments and streamed images reduce memory. Quality+ stops on training-view PSNR, not held-out scores.

Correctness evidence

74 test modules cover gradients, backward parity, bf16 Adam, SSIM, sorting and lifecycle. Authors report fixed-model cross-vendor replay checks, but also same-seed training variation and a long-lived test-process failure. No tests were run here.

Benchmark discipline

Nine scenes, 246 held-out views, equal scene weighting; CSV arithmetic reproduced. One seed and OS/backend differences limit generalization. Cached completed CSVs are not fresh measurements.

Reviewed master: 26a4ca2d81ab8495848cd9f11e2f537049f2946a. Release v1.0.0 is earlier, and published RTX 4090 measurements have separate historical source provenance.

Desktop user authority, not tenant isolation. Optional reconstruction downloads mutable latest binaries without pinned checksums and executes subprocesses. Native inputs and dependencies require trust.

Hub PLY export uses temporary-file replacement. PLY is not a full optimizer checkpoint; continuation is in-memory and benchmark recovery is per scene. No full crash-resume guarantee was found.

Pin source/dependencies, audit tool/mask/data terms, retain PLYs and renders, measure multiple seeds and end-to-end time. No installs, GPU runs or model/dataset downloads were performed here.

Verdict

The call, and why.

⚠️ Interesting

Substantive Slang training with credible reported speed and inspectable numerical tests. Optimization-only timing, single-seed variation, native tool trust and restrictive optional masks prevent a turnkey production recommendation. Static review; GPU claims were not independently reproduced.
