Key points

What matters most, in order.

1

Useful architecture, narrower product

Shared anatomy, discrete cavity routing and caller-supplied constraints reduce cross-trade drift. The separate editor and four trade plugins—not this package alone—produce the showcased house.

2

A clean audit can hide missing data

Working-space checks skip missing or nonfinite measurements; fixture checks can skip absent nearby-fixture data. Validate completeness and rule applicability before treating zero violations as evidence.

3

Own acceptance and rollback

Automatic reservation is not gated by the final ok result. Keep rejected diagnostic paths out of shared occupancy, assert target endpoints, and rebuild state from immutable saved scenes.

Shared anatomy and rules

Anatomy resolves common geometry; placement thresholds tighten the same table used for auditing. Rule references and measurements remain caller-supplied, not independently verified code authority.

Routing with explicit diagnostics

The solver tries a hard-free route, a degraded diagnostic search, then a fallback. A returned path is not itself acceptance.

Numerical limitations

Graph compilation targets 580 vertices and 24 stations per wall. Search retains 16 Pareto labels per state; sampled footprint checks cap general segment sampling at 64 steps. Neither completeness nor global shortest-path optimality follows.

Nonfinite endpoints become zero components, and nonfinite extents become zero. Static gravity-shaping inspection also identifies a possible endpoint mismatch when available head is insufficient; this was not reproduced. Validate physical inputs and independently check endpoints and segment slopes.

Audit and recovery traps

Working-space measurements can be absent without violations; rule validation is separate. Final routing reservation is not conditioned on ok. Explicit acceptance and rollback are required.

State and privacy

WeakMap caches depend on scene identity. Reservations are memory-only, with explicit unreserve; the host owns durable saves, multi-route transactions and restart reconstruction. No runtime network or telemetry integration was observed. Validate untrusted models and impose resource limits; host privacy/security are separate.

Verdict

The call, and why.

📚 Study

Study the shared geometry and placement/audit rule design. Missing measurements can pass audits, failed routes can reserve space, and bounded search does not establish constructability. Require independent geometry, endpoint and engineering validation before real design use.
