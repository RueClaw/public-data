Key points

What matters most, in order.

1

A dataset, not an agent

The authors report 7,262 tasks across 318 subfields and 140 work activities. The release ships tables, methods and figures—not a backend, agent loop or self-hostable website.

2

Elo does not mean success rate

A model compares which tasks another model would be more likely to complete. No Opus 5 task executions underpin these scores; the hypothetical setup delegates physical work to humans.

3

Transparent methods, limited validation

O*NET ratings were used both to tune and evaluate prompts. Timing checks cover a small wet-lab subset; full generation code, inputs and figure reproduction are not shipped.

Task taxonomy, substeps, annual-hours components, paper prevalence, RL feasibility and model-judged Elo form a reusable research vocabulary. Counts and statistics are author-reported, not independently recomputed. Purpose and dictionary.

The RL index combines three synthetic dimensions; explained variance is not evidence of predictive automation accuracy. Reported Elo split-half correlation is 0.87, but consistency between judges is not external task-performance validation. Dimensions and evaluation.

The rating prompt was tuned on its O*NET evaluation tasks. Papers are selected English-language, cited, open-access journal articles; a small quote audit is not a comprehensive labeling audit. Methods and sampling.

Documented flow: taxonomy → paper expansion → ratings → step timing → dimensions → activity and hour-weighted summaries. The executable generation pipeline is not included. Methodology.

Join on task and full scope, not text alone. Universal timing and annual-hours tables have different granularity. Preserve Namibia’s NA code as text. Forty-three substeps lack scores and one task lacks Elo; detailed exceptions override broad completeness language. Join conventions; Missingness.

Annual hours are mostly model-derived, not time diaries. Figures and researcher counts require external inputs/code, so snapshot recovery is possible but complete regeneration is not. Time-use limits; Figure provenance.

Verdict

The call, and why.

📚 Study

Useful for scientific-work taxonomy and hypothesis generation. AI Elo rankings are judgments, not task executions; most time-use components are synthetic and the upstream pipeline is not reproducible from this release. Static documentation review only; dataset payloads and website were not tested.
