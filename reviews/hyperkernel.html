Key points

What matters most, in order.

1

Correct identity: Hyperserve, not a sandbox

Four fixed modes run DeepSeek-V4.1-Flash, openpilot frame inference, Evo2 and MG3. Only the LLM mode serves HTTP; this is not an OS kernel or a published kernel-generation compiler.

2

Meaningful scheduling, narrow hardware

Prefix-page reuse, prefill pacing, preemption and pinned-memory GPU rings are implemented. The LLM requires four B300s and about 203 GB of host RAM for its shared table alone; C5/C6/C7 profiles do not impose separate five/six/seven-lane caps.

3

Trust the artifacts, protect the service

Cubins and bundle layouts execute with native GPU authority. Loopback and optional bearer auth are useful, but IPC, deadlines and tenant separation need hardening; the optional serve wrapper drops the API-key environment variable.

Specialized inference

Four model runners with local checkpoints. Chat/completions support streaming, tool-call formatting and logprobs, but not Responses or structured-output constraints. Tool calls are returned as data, not executed.

Evidence versus claims

All 11 reference descriptors were decompressed and parsed without executing source. Five LLM descriptors declare four ranks, 1,048,576 context positions and 202,758,032,400 host-table bytes. These facts do not prove runtime capacity, numerical parity or speed.

Testing posture

137 Rust test annotations and eight integration-test files were inventoried; none was run. Fake-device tests cover host contracts, while some bundle/checkpoint checks are ignored by default. No GitHub workflows, releases, tags or Actions runs were found at retrieval.

Host policy / device protocol

CLI → trusted bundle and checkpoint loader → rank processes and peer memory → scheduler/page pools → pinned-memory command/reply rings → native megakernel. The Kernel trait supports deterministic fake-device tests.

Native trust boundary

Bundles contain executable cubins; original kernel sources and a reproducible generator pipeline are absent. Local rank IPC lacks explicit peer-credential validation and restrictive-mode setup in the inspected path. Processes cooperate; they are not tenant sandboxes.

HTTP boundary

Loopback default, optional bearer key, 256 connections and 16 MiB bodies. Bodies are read before authentication; per-read timeouts are not total deadlines, and no socket write timeout was found. Use authenticated TLS ingress and external limits. The dsv41 wrapper uses env -i without passing HYPERSERVE_API_KEY.

Recovery

Prefix cache, jobs and metrics are volatile. Surfaced errors refuse work; the supervisor terminates other ranks after one exits, with no request replay or automatic restart. Validate failure cleanup and stalled-device behavior separately.
