Key points

What matters most, in order.

1

A real architectural distinction

Linux runs as compiled wasm; only arm64 user programs are emulated. Linux-managed page tables are walked in software, not hardware virtualization.

2

Integration is not isolation

Guest preview pages share the desktop origin. The CLI enables host-socket networking by default, and host mounts are writable unless restricted; the SDK network default is off.

3

Recovery is carefully designed

Read-only images, ext4 overlays, strict IndexedDB transactions and snapshot compatibility checks are promising. Safe mode preserves broken overlays; browser storage and snapshots still need backups.

Linux semantics, emulated programs

Kernel syscalls run as wasm; unmodified arm64 packages run through kwemu. Page-table implementation and host runtime substantiate the architecture, not universal compatibility.

Persistence and recovery

Guest init retains damaged overlays. Disk transactions save blocks and generations together; snapshots validate disks, devices and CPU count. Snapshots do not include disk copies.

Host authority

Preview relay explicitly permits trusted content only; the iframe has no sandbox and shares the desktop origin. Same-origin storage and parent objects are reachable. COOP/COEP are not user authentication.

CLI networking defaults to host sockets and loopback reachability. Host mounts document an intermediate-directory symlink race. Worker mode is not an independent security domain.

Privacy and supply chain

Browser TCP uses Wisp; mirrors and default Picsum wallpaper add egress. Disks and snapshots can retain secrets. Component notices distinguish MIT SDK/page from GPL kernel and renderer terms. Pinned inputs and OIDC publication help, but do not independently authenticate a compromised release manifest.

Start Node with guest networking disabled, no host mounts and disposable data. Add capabilities explicitly and use independent OS isolation/resource limits for hostile code. Export disk backups; restore requires matching machine state. See hosting configuration.

Verdict

The call, and why.

⚠️ Interesting

Compelling for trusted local labs and embedded development, not a ready-made hostile-code boundary. Same-origin previews, host-reachable Node networking and writable mounts need deliberate restrictions. Static review only; no runtime or performance claims independently reproduced.
