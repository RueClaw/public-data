Key points

What matters most, in order.

1

A real native GUI library

Oscar Soirey’s Raven provides retained widgets, docking, XML hot reload and visual design tools. UI ownership, worker painting and an ordered render queue are distinct; multithreading does not mean arbitrary-thread widget mutation.

2

Current CI is not green

Build run 42399389852 for the reviewed SHA failed its Linux Test step after building successfully. API/ABI stabilization, other-platform test execution, full shaping and several input-method integrations remain unfinished.

3

Assets and web views cross trust boundaries

XML images can fetch URLs using curl or WinHTTP without a private-address denylist. Web views drive a full installed browser: pipes and temporary profiles help, but no-sandbox overrides, host callbacks, tracing and retained crash logs matter.

XML design loop

Declared widgets, includes and live tree comparison support iterative editor construction. The watcher retries partial edits, but this is neither a document sandbox nor crash recovery.

Rendering and performance

Paint splits large subtrees at 512 widgets and merges in order. Glass uses offscreen copies and blur passes. The README’s CPU timings and approximately 1.3 MB binary claim were not reproduced; its glass test used software Vulkan and explicitly did not measure GPU performance.

Tests and maturity

Substantial headless suites and a Wayland test compositor are present. Vulkan/browser tests can skip. The exact-SHA Linux test job failed; the failing assertion was not retrieved. Cross-platform builds do not prove native input, graphics or browser correctness. The roadmap records API/ABI and text-input gaps.

Ownership and limits

Frame packets isolate render work from UI mutation. Generational handles have only eight generation bits and wrap after 256 slot reuses; they are not permanent stale-handle protection or a sandbox.

Local resources and network

XML resolves absolute/local paths and HTTP image URLs. The downloader uses bounded HTTP/HTTPS fetching, but no internal-address denylist. Unix curl inherits environment and default config; executable lookup and proxy settings are part of the trust boundary. Untrusted documents need application-enforced resource restrictions.

Browser bridge and privacy

Browser startup uses CDP pipes and a separate profile, but root or presence of RAVEN_WEB_NO_SANDBOX disables Chromium sandboxing. Network-suppression flags are not an egress firewall. Message dispatch forwards page payloads without an origin authorization check in that path; privileged host callbacks must validate navigation and messages. Persistent profiles, debug tracing and preserved crash logs change retention. Unix browser processes inherit the environment.

Persistence

XML/theme/designer saves use direct wb writes, not atomic replacement or journaling. Keep backups/version control; hot reload is not power-loss recovery. Browser failures notify views rather than providing durable session replay.
