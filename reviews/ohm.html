Reuse and qualification

Public-interface hashes can avoid downstream recompilation while relinking changed dependencies. Check/build sharing and worktree seeding reduce repeated work. Untracked procedural-macro, build-script and native-helper inputs remain correctness risks.

Privacy and recovery

User build code can access files and network. Artifacts retain source-derived material. Verdict

The call, and why.

⚠️ Interesting

Substantive release engineering and reuse optimizations, but potentially unsound compilation is an explicit tradeoff. Keep upstream Rust authoritative for CI, final tests and shipping. Static review only; speedups and compiler correctness were not independently reproduced.
