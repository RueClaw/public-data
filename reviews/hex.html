Key points

What matters most, in order.

1

Local speech, optional remote processing

Core speech inference runs on-device. Updates and model downloads use the network; optional OpenCode rewrites and custom fetch can send content beyond it.

2

Useful controls, not a sandbox

The API uses a random bearer token and protected discovery file. Script approvals are content-hashed, but subprocesses run with user permissions.

3

History Off does not delete history

Default retention is seven days with bounded atomic storage. Turning it Off preserves existing entries; explicitly clear them. Owner-only is not encryption.

Pipeline

Shortcut → microphone → local inference → optional processing → insertion. The API authenticates before dispatch, bounds input and listens only on loopback. Same-user readers of the token remain trusted. Minimal subprocess environments do not sandbox scripts.

Recovery and updates

Staged/synced writes and changed-field settings merges reduce loss. Model checksums and platform signature validation are positive static evidence, not runtime proof. Managed feature locks are macOS-only.
