Key points

What matters most, in order.

1

Workflows, not enforced security

All seven skills request explicit invocation. Helpers can still run shell commands, raw HTML and target repositories with host authority.

2

Good evidence and preservation discipline

Screenshot provenance, base/head worktrees, small green rounds and mutation-based proof before deleting tests are useful patterns, not equivalence guarantees.

3

Reporting is not a correctness gate

The reporter preserves the producer exit code, accepts empty results and trusts supplied verdicts. Paid TTS discovery and rich report publication need separate privacy and consent checks.

Complete inventory, analysis and pinned evidence

Configuration invokes sh -c with inherited environment. Slide specs are imported JavaScript and scene HTML executes in Chromium. No sandbox or egress firewall is provided.

An available ElevenLabs key selects paid narration unless overridden. Media preview fetches Google Fonts. Evaluation reports retain inputs, outputs and tool data without redaction; a real private-repository/public-Pages refusal is narrower than content privacy.

Failed records need not fail CI when the producer exits zero. Empty reports can display green, string booleans are coerced, and changed-only selection is filename-based. Review fingerprints omit top-level passed, rule and note. Pages retry is bounded but publication and linking are not atomic.
