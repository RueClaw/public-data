Key points

What matters, in order.

1

Fast, and it checks out

Verified against a real 4.46M-entry index on this machine: fuzzy name search, one-typo tolerance (mian.rs finds main.rs), content grep, symbol lookup, and a 10 ms end-to-end CLI query. The author's 0.13 ms claim is consistent with the observed 111 µs daemon time.

2

Agent-native interface

JSON lines over a local Unix socket or fsearch stdio: one query in, one JSON answer out with scores, sizes, mtimes and microsecond timings. CLI, daemon and any app share one index with a single-writer lock.

3

Small, local, no network surface

Nine thousand lines of Rust, eight dependencies, zero networking crates, no telemetry. The entire trust question reduces to a small auditable local binary.

4

Three days old, zero tests, and the FDA question

v0.1.0 from a single author with no automated tests. Full coverage requires granting Full Disk Access — a whole-disk read grant to a brand-new binary. It works fine without FDA, skipping consent-gated folders silently. Start there.

fsearch 'readme in:~/Developer'
fsearch 'type:image size:>5mb mtime:<7d'
fsearch 'ext:rs regex:fn\s+\w+_dir'
fsearch 'sym:apply_dir'

Fuzzy by default; 5+ letter words forgive one typo. Operators: 'exact ^prefix suffix$ !exclude. Filters: ext: type: kind: in: size: mtime: re: path: grep: regex: sym: limit:. Content search is smart-case.

  • Clean cargo build --release, 22 s.
  • Daemon indexed the disk with an isolated index dir: 4,456,265 entries, 194 MB.
  • Name search, typo tolerance, content grep with correct line output, sym: lookup — all correct.
  • New file appeared in results ~1 s after creation (FSEvents path works).
  • JSON output: took_us: 111; CLI wall time 10 ms.
  • Test daemon and index removed after the run.
  • Zero automated tests; v0.1.0; single author; three days old.
  • Full Disk Access = whole-disk read grant to the daemon. Mitigations: no network deps, open source, small codebase, works without FDA.
  • macOS-only by design.
  • Unix socket relies on ~/Library/Application Support privacy; no explicit socket permission tightening.
  • ~84 unsafe blocks (syscalls/mmap/FSEvents), unreviewed.

Verdict

The call.

✅ Deploy candidate

The fastest local file-search tool we've verified, in a small auditable package with an agent-native interface. The age and zero-test posture argue for watching rather than trusting blindly — but the blast radius of a local search tool is small, it asks for no network, and it works exactly as described. Run without Full Disk Access until it earns the grant.
