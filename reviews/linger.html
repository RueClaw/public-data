What matters most, in order.

Consent is path-specific

Connector writes bind stored content to approval and recheck grants. Host actions use a separate policy; Codex is unsandboxed and Pi runs without review.

2

Local does not mean offline

“Another Me” coordinates agents, reads connected sources, maintains a personal wiki and follows up proactively. Rooms, Tasks and Documents provide contexts. The server owns business records and permissions; a Go Computer Daemon connects outward and launches the chosen runtime. This is neither a memory-only library nor an isolated agent sandbox.

The desktop app can install a local server; Compose serves the workspace across computers. Agents and model endpoints operate from connected computers even when the server is elsewhere. There are several trust/storage locations, not one local database. See docs/architecture.md and docs/self-hosting.md.

Checked knowledge structure, not guaranteed truth

The owner-scoped wiki and per-agent memory are separate. Documentation describes typed entity/session pages, citations and app-written change logs. apps/node-services/src/llm-wiki/wiki-candidate-validation.ts checks routed targets, incoming citations and source coverage. These are useful provenance/anti-loss checks, not factual entailment proofs or prompt-injection immunity.

Search combines PostgreSQL keyword and temporal ranks with reciprocal-rank fusion; it needs no embedding/reranker model. Alternate phrasings help lexical and cross-language recall. Summarized sections and short change logs are not complete audit archives. docs/wiki-and-memory.md describes extraction after five successful Room runs and idle consolidation; delegated Tasks and document work do not feed that agent-memory path.

Content-bound connector consent

apps/teamhub/internal/agentconnectedapps/confirmation.go binds confirmation to a connection and stored action, pins draft content, rechecks current grants/connection state and refuses changed drafts/canvases. Unknown provider outcomes are distinguished from definitive failure. This is good duplicate-send defense, not distributed transactional exactly-once execution.

This guarantee belongs to the connector path. Desktop clicks and shell commands have different policy surfaces. “External apps write only after confirmation” must not be read as universal human confirmation across every runtime/tool.

Host execution, not a sandbox

apps/computer/local-daemon/internal/workspace/codex_projection.go supplies Codex with sandbox_mode="danger-full-access". apps/computer/local-daemon/internal/permission/reviewer.go fast-allows selected reads, recognized shell operations and navigation shapes; other intercepted calls go to review. Failures return unavailable; navigation reuse is run-scoped. That is defense in depth, not OS isolation. docs/architecture.md explicitly says Pi runs without review.

Per-context folders, read-only memory projections and separate browser profiles organize work; they do not separate same-account processes from files, credentials or signed-in apps. Hostile pages, email and documents reach an agent with real authority. Use a dedicated OS account or disposable machine, narrow integration accounts and no unrelated secrets. No exploit or bypass resistance was tested here.

Authentication, Network and Credential Boundaries

  • Real API authorization: action allowlists, tenant-qualified queries, current room/document access and task-context restrictions exist in apps/teamhub/internal/agentauth/agentauth.go. This is positive API isolation, not proof of safe unrelated-tenant cohosting.
  • Session lifecycle: apps/teamhub/internal/account/session.go stores token digests, locks against stale password verification and rechecks renewed sessions. Complete route-level auth/CSRF coverage was not audited.
  • Broad local-origin trust: apps/teamhub/internal/app/cors.go accepts configured origins plus localhost, loopback and private-IP origins, reflecting them with credentials enabled. This expands trust beyond an explicit allowlist; CORS alone does not bypass authentication and exploitability was not tested.
  • Shared service trust: SECURITY.md documents seed-derived service credentials and a deployment encryption key. apps/teamhub/internal/secretbox/secretbox.go uses AES-256-GCM for saved secrets, not end-to-end document encryption against the server operator. apps/node-services/src/service-bearer-auth.ts compares token digests timing-safely.
  • Local credential files: apps/desktop/src/main/computer-credential.ts atomically writes owner-only files, explicitly not OS keychain storage, and accepts ws or wss. Same-account compromise remains relevant.
  • Remote setup: Compose defaults database/media ports to loopback. SECURITY requires private secrets and HTTPS before exposure. The shorter self-hosting example shows HTTP/ws and only one replacement secret; follow the stronger security guidance, not that example verbatim. Replace database defaults and the example owner password too.

Privacy, Provider Flows and Costs

Local inference is not an offline feature matrix. Codex, Claude Code and Pi can use remote subscriptions/API endpoints; background memory/wiki work follows runtime routing. The selected provider receives required context. Composio mediates connected apps and holds upstream credentials; mail/calendar/chat cross that integration boundary. Browser control can use existing signed-in Chrome sessions.

docs/voice.md explicitly sends transcription/archive-recovery audio to Soniox and uses xAI for live voice. Saved voice keys are deployment-wide, and the documentation allows any signed-in person to replace them unless environment keys lock them. apps/teamhub/internal/voicekey/voicekey.go implements environment precedence and encrypted stored keys. This is shared operational authority, not tenant-isolated billing.

Local inference avoids vendor token charges, not hardware/RAM/storage/power costs. Remote inference, Composio and voice carry their own quotas/pricing; no current price quote or universal spending cap was verified. Background consolidation and proactive/parallel agents consume inference too. Diagnostics upload is optional and user-confirmed, with file/receiver preview and redaction (docs/diagnostics-upload.md); receiver retention is a recommendation, not independently verified hosted behavior. Obtain participant consent before meeting recording.

Persistence, Retention, Export, Delete and Recovery

PostgreSQL holds business records, permissions and jobs; local workspaces and daemon SQLite retain execution state; artifacts/media add file storage. apps/computer/local-daemon/internal/daemon/operation_ledger.go provides persisted operation handling. Reconnect replay and uncertain-action handling improve resilience but cannot undo external effects.

apps/teamhub/internal/retention/retention.go explicitly excludes business content—messages, room events, documents, wiki and recordings—from age deletion. apps/teamhub/internal/store/queries/retention.sql cleans working data in bounded batches, including eligible 30-day document events and seven-day non-recording voice state. Disconnecting an app or deleting a chat must not be assumed to erase derived memory, logs, backups or provider copies.

apps/teamhub/internal/document/export.go validates media type, byte length, SHA-256 and asset/thread correspondence for Markdown, text, HTML or blocks exports. apps/teamhub/internal/roomcreation/deletion.go waits for membership revocation before finalizing a room deletion event. These are narrower lifecycle capabilities, not a demonstrated full-account export or secure-erasure contract.

No comprehensive, tested deployment backup/restore runbook was established in the reviewed documentation. Inventory the database, artifact/media files, daemon state, workspaces and encryption keys; take consistent backups and rehearse isolated restore. DB-only backup may omit files and cannot recover lost encryption keys. Update rollback is not data rollback.

Dependencies, Install, Updates and Maturity

The workspace pins pnpm, requires Node 26, and includes lockfiles, Go sums, generated contracts and dependency build-script allowlists. Native dependencies include SQLite, image/media libraries, browser tooling and Electron. Patches to Hocuspocus, LiveKit, Deep Agents and an alpha Playwright build add compatibility maintenance. No advisory scan was run; locked versions do not establish safety. See package.json and pnpm-workspace.yaml.

Mac documentation describes unsigned packages and quarantine removal. SHA256SUMS establishes consistency only relative to a trusted manifest. apps/computer/local-daemon/internal/selfupdate/stager.go downloads a server-advertised archive, bounds size, verifies hash and executes its installer. apps/computer/local-daemon/internal/selfupdate/selfupdate.go handles staged activation, confirmation and rollback. The server origin and manifest are code-distribution authorities; matching hashes are not independent publisher signatures.

.github/workflows/ci.yml provides path-aware gates, frontend shards and daemon Go checks. It explicitly leaves heavier node-services, voice, integration, container and E2E suites local. Many targeted tests address grants, confirmations, sessions and updates, but none ran here and no passing CI status is asserted.

Public GitHub metadata retrieved November 19 showed creation November 10, last push November 19, 1,382 stars, 98 forks and 38 open issues/PRs combined. Adoption Gate

Start with synthetic data on a dedicated account, local-only inference and connectors/voice disabled. Test human confirmation, revocation, reconnect, ambiguous effects, provider spending and complete restore before real accounts. Verify the chosen runtime's actual policy behavior, especially Pi. Do not expose it as an untrusted multi-tenant service or assume the license permits managed hosting.

Bottom line: worth studying and carefully piloting for its server/host split, checked wiki and content-bound approvals. This static review does not justify a “fully private, safely autonomous, free Claude-class assistant” conclusion.
