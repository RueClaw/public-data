Key points

What matters most, in order.

1

Hardware eligibility and evidence matter

The README lists 123 boards but only three in daily use. Still occupants are held by timers, not continuously measured; the detector is a bundled binary without its implementation/build sources in this tree.

2

Local-first, not a privacy boundary

Writes and flashing have explicit guards, but read WebSocket handlers lack admin checks despite the admin-only panel. Diagnostics include household topology; detection history persists subject to seven-day and event-count pruning.

3

Flashing is not transactional

CRC32 caching does not authenticate firmware. OTA jobs are in memory, permit-join can be renewed for up to 30 minutes, and model verification is not rollback or proof of correct pin mapping.

Room and link tuning

Discovery, calibration, sensitivity, occupancy entities and snapshot/delta panel updates separate the host UI from device sensing. Engine evidence.

Guarded transport

Writes default off; protected/non-Ripple sensing targets are refused. Serialized reads and exponential backoff reduce pressure. Firmware conversion has separate guards. Transport.

Do not overread the tests

19 Python test files plus JavaScript checks cover host logic using synthetic fixtures and fake devices. No checked-in workflow and zero public Actions runs were observed. No RF accuracy or 100-switch benchmark was verified.

Inside Home Assistant, not a sandbox

Runtime connects Engine, HA storage, adapters and entities. ZHA setup writes a custom quirk; Z2M saves an executable converter over MQTT, even when device writes are disabled. Protect configuration and bridge-topic permissions.

Read authorization and diagnostics

The admin-only sidebar does not make state, snapshot, subscription and history handlers admin-only. HA authentication still applies; this is not anonymous access. Diagnostics explicitly redact only protected-device options and include other household details. WebSocket evidence · Diagnostics.

Recovery and retention

Settings/history saves are delayed two/30 seconds. History prunes on load/add to seven days or 50,000 events; backups/HA recorder may retain other copies. OTA jobs are not persisted; unload cancels them. No automatic rollback is demonstrated. History · Flasher.

Firmware and licensing limits

The shipped detector binary lacks corresponding implementation/build sources here. CRC32 is not a signature. PolyForm Noncommercial is source-available, not unrestricted open source; the CLA permits commercial relicensing. Board overrides are trusted inputs, including interpolated model strings in generated converter code. See the full review for exact firmware hash, provenance, dependency terms and all citations.

Verdict

The call, and why.

⚠️ Interesting

A worthwhile noncommercial hardware experiment with thoughtful host-side guards, but binary-only sensing firmware, limited daily-tested boards and incomplete recovery evidence prevent a deployment recommendation. Static review only; tests and hardware experiments were not run.
