Evidence

Full review with revision-pinned source citations and license details

Typed authoring emits a JSON workflow document that the DSL validates and interprets with chain, map, parallel, bounded-loop and child-workflow composition. Host seams dispatch agent work to runNode, decisions to runJudge, effects to runEffect and optionally code to runCode. Hosts retain policy, credentials, budgets and persistence.
