Key points

What matters most, in order.

1

1M capacity is not 1M retrieval proof

longctx zeroes KV and benchmarks simulated positions. Its B=4 throughput assumes 2.5 accepted tokens per step; a real million-token three-needle soak is explicitly unfinished.

2

Fast paths have numerical tradeoffs

NVFP4 weights and Q4 KV need quality validation beyond speculative token parity. Top-p/top-k use histogram cutoffs, not exact sorted filtering; B=1 and batched accumulation can tie-break differently.

3

Keep the server off untrusted networks

Default all-interface binding, optional authentication and blocking single-client I/O need hardening. Oversized API keys have a static fail-open edge; the sample system service omits an unprivileged user.

Specialization that matters

48 logical visits over 24 physical layers, eight global attention visits, local rings, adaptive 2/4/8 target verification and prompt-lookup drafting. Source claims 589.5 tok/s code, 771.6 copy/RAG and 332.5 chat: different workloads, not a universal speed.

main loads local tensors; weights plans and converts weights; engine owns KV, prefill, decode and graphs. Runtime and weight arenas reduce allocation churn. Above 512K context, non-exact mode automatically uses pinned host embeddings: zero expert spill is not zero host memory.

Four host prefix checkpoints and a side-request shield improve repeated-prompt latency, but carry no per-tenant isolation. KV/request/RNG state is volatile; service restart reloads the model rather than resuming a response.

Do not use the sample unit unchanged: it binds all interfaces, leaves authentication optional, omits User= and enables optional ablation. Use unprivileged loopback-only serving behind authenticated TLS, request deadlines and rate limits. Synchronous recv occurs before authentication.

Static auth finding: formatting Bearer plus a key longer than 249 bytes into a 256-byte buffer falls back to an empty expected string, matching an absent header. Fail closed and validate key length. No exploit was executed.
