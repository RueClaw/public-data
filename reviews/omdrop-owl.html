Key points

What matters most, in order.

1

Card-tested is not driver-tested

The whole iwlwifi driver is enabled as tested, including unvalidated cards. Public issue #16 reports Intel 7265 firmware crashes at this revision; this was not independently reproduced. Match PCI ID, firmware, kernel and mode.

2

Native interoperability has a real cost

MT7925 shared mode requires AP channel 6, 44 or 149. Intel exclusive mode takes Wi-Fi offline. Recovery records connection state, but visible status is not proof of a healthy radio or a successful transfer.

3

Privileged desktop integration, not a sandbox

Active local users may invoke the fixed-path root helper without an admin prompt. Fixed interface names, debugfs changes and nearby wireless input require care. Ten command-double tests exist; no CI workflow or runtime verification was established.

Two radio modes

Shared mode coexists with a compatible AP; exclusive mode uses IBSS, sometimes converting the station in place. Restoration keeps the previous connection UUID and IPv6 setting and performs bounded reconnect retries.

Targeted patches

Seven patches implement rate/address controls, scheduling, election, no-ACK, channel pinning and retry/liveness workarounds. Queue-full retries retain unicast frames rather than dropping them; these are not general protocol-correctness proofs.

Driver profile → station/shared-channel or exclusive IBSS setup → monitor interface → OWL creates awdl0 → periodic service advertisements. Receiver acceptance and TLS policy are outside this repository. Shared startup also requires an IPv4 gateway ping, which can reject otherwise usable networks.

Safety boundaries

polkit allows active local sessions to change discoverability without admin authentication; start 0 is indefinite. Cleanup deletes fixed mon0/awdlibss0 names without ownership proof, does not undo debugfs mounting and can report success despite restoration errors. Inspect diagnostic logs for network identifiers before sharing.

License caveats

No top-level LICENSE; GitHub reports null. Debian packaging explicitly labels the helper, profiles and OWL patches GPL-3.0-or-later, upstream tools GPL-2.0-only and radiotap ISC. OWL header confirms GPLv3-or-later. omdrop-awdl’s license text describes kernel patches despite userspace imports; clarify scope and original build/test-file grants before redistribution. Preserve notices and applicable corresponding-source obligations.

Verdict

The call, and why.

⚠️ Interesting

A hardware-specific pilot, not a universal AirDrop replacement. Targeted OWL patches and recovery logic are useful, but Intel mode disconnects Wi-Fi, driver-wide enablement exceeds tested hardware, and licensing documentation needs clarification. Prefer conventional LAN sharing unless native AirDrop is essential.
