## Text

Every company should own their secure cloud dev environment where agents can change code, run the full application, and verify their work. At @depthfirstlabs  we care tremendously about this and today we share how we built our environment.

Each developer gets a persistent devbox, and each task gets its own application stack, database, and workflow state, so agents work in parallel. Engineers have flexibility to switch between Codex, Claude Code, and other agents without losing context.

The environment runs inside our private AWS network, with access controlled through @Tailscale and package requests checked by depthfirst’s Dependency Firewall in configured build and registry paths.

When an agent finishes an iteration, it can share reproduction steps, video evidence, and a private preview URL. We can open the exact environment it tested and review the behavior ourselves.

We had it operational within a week.
