## Text

Someone turned the hardest parts of LLM inference engineering into a course where you have to fix the performance problems yourself.

it’s called tiny-llm, an open-source course for building a small vLLM-style inference engine around Qwen3.

you build a working model, then fix the bottlenecks that make it slow.

> implement attention and text generation
> add a KV cache to reuse previous calculations
> work with packed 4-bit weights
> write faster operations in C++ and Metal
> handle multiple requests with batching and paged memory

the four-week course also covers a small coding agent with tool calls, checkpoints and context management.
each stage includes exercises, reference solutions, tests and measurements.

i like that you have to measure the improvements yourself.

it uses MLX, C++ and Metal on Apple Silicon. No NVIDIA GPU required.

the introductory path supports Qwen3-0.6B on an 8GB Mac, while some later checkpoints remain under development.
