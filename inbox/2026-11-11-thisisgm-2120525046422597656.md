# Well, that was fun.

- Author: @thisisgm (GM)
- Posted: 2026-11-11T14:32:23Z
- Bookmarked via: X

## Text

Well, that was fun.

As I said in the video three months ago, Flea was built to one day be the default file manager for Omarchy. Last night, Folio was merged as Omarchy's new default.

There's not much I can say other than thank you to everyone who supported the project. This has been one of the most wonderful experiences of my journey in tech so far.

I made all of this happen on a very tight budget. Meals were skipped, sleep was lost, and the journey took a real toll on my mental and physical health. I was solo the entire time, maintaining Flea and pushing the limits of what a file manager on Linux could be. We broke every benchmark we could find and hit unheard-of speeds. It was a generational and extremely fun run.

The good news is that Folio is C++ and Qt, so most of the front-end optimizations from Flea 0.3.12 can be ported over, which means it can still be the second-fastest file manager on Linux. I'll send as many PRs as I can so the file manager does justice to the wonderful project that Omarchy is.

The bad news is that I can't keep up this cash and mental burn for Flea now that it can never be the default. That was the main pitch to sponsors, and it's what drove me to push as hard as I did these last few months. I really tried my best to keep that pace going, but it isn't sustainable anymore.

Flea is not stopping. Starting with 0.4.3, it moves to a much slower pace. Bug and security fixes come first, and new features will land when time and budget allow. I had up to 16 more releases planned, and they will still happen, just over a much longer timeline. On performance, as of this writing there is simply nothing else out there that compares to Flea, and that is a win I will carry forever.

"Why don't you just open it up to other distros?" To be completely honest, I'm only interested in developing for Omarchy. I have no doubt it's the best the Linux desktop gets, and it's hard to develop for things you don't use. If I can't promise you something I'd use myself, there's no point.

If there's enough interest, I may pick the pace back up. For now I'm still grieving the default dream, so I'm taking it one release at a time.

Thank you to all 120+ contributors, and to superwhisper and zeroramp for sponsoring the project.

The sprint is over, but Flea isn't.
