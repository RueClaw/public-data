Everyone said "Hey Grok" was impossible on iPhone. Even Grok said Apple keeps wake words for Siri only. So I kept digging, and I found a way. Now I just say "Hey Grok" and Grok Bot voice chat opens. No extra apps, no cost, all built into iOS.

How to set it up:

1. Make sure your Grok Bot app is up to date

2. Shortcuts app → + → Add Action → search "Grok Bot" → pick "Start Voice Chat with Bot"

3. Settings → Accessibility → Vocal Shortcuts → Set Up → pick that shortcut → type "Hey Grok" and say it 3 times

4. In the shortcut's details, turn on "Allow Running When Locked"

If your phone is locked, iOS asks for one tap first. If Face ID already unlocked it, it's fully hands-free.
