Big moment for Local AI!

running models locally always had one hard rule. if the weights didn't fit in GPU VRAM or unified memory, the model didn't work.

that rule is why running a 180B-class open model has meant buying a $10-20K workstation.

but this is about to change.

in the video below, i'm running Qwen 3.8 Flash Next, a 180B model, on an M4 Max with 64 GB of memory.

it runs in OpenCode at 56 tokens/sec, with a 2-bit quant and a 64k context.

this sounds impossible, but it works because of how today's open models are built.

they are sparse mixture-of-experts (MoE) models. each layer holds many small sub-networks called experts, and a router picks only a few of them per token.

Qwen 3.8 Flash Next has 180B parameters, but only ~6B run on any given token. so ~97% of the model sits idle on every token, and local runners still kept all of it in VRAM.

SSD expert streaming fixes this. it keeps attention and the session's most-reused experts in fast GPU or unified memory.

everything else stays on the NVMe SSD, and the engine reads it only when the router picks it.

however, it's not as simple as it sounds. a naive version of SSD streaming crawls at a couple of tokens/sec, and there are four reasons why:

↳ a basic cache evicts experts the next few tokens need again.

↳ layer-by-layer disk reads leave the GPU and SSD waiting on each other.

↳ speculative decoding verifies several tokens at once, so each step touches more experts.

↳ long prompts flush the cache that decoding depends on.

Magnitude, an open-source inference engine launching today, solves all four together:

↳ it ranks experts by reuse and keeps the top ones in GPU memory, so most tokens never touch the disk.

↳ it peeks at upcoming tokens and prefetches their experts before the GPU stalls.

↳ it schedules direct NVMe reads across layers and bypasses OS swap entirely.

↳ during prefill, it reads each cold expert once per layer while the GPU computes, so long prompts don't wipe the hot cache.

streaming never writes to the SSD, so there's no flash wear. more RAM or VRAM still helps, since it keeps more experts hot.

on first launch, Magnitude profiles the hardware, predicts tokens/sec for each model before download, and tunes kernels for that exact chip. there are no flags to set.

it runs on Apple Silicon, NVIDIA, AMD, Intel, or plain CPU, as a desktop app, CLI, or Docker image. Claude Code, Codex, OpenCode, and Cline connect in one click, with an OpenAI-compatible API for everything else.

i think this is the biggest change to local inference since quantization. the limit on what runs at home moves from VRAM size to SSD speed.

a fast NVMe drive costs a fraction of a high-end GPU.

it's free, Apache 2.0 licensed, and fully local.
